# Uptime Monitor

Локальный веб-монитор HTTP и HTTPS. На главной странице отображаются статусы, последние проверки и доступность за сутки. На странице сайта есть график задержек и история инцидентов.

## Запуск

В папке проекта с Go 1.23 или новее выполните:

```powershell
go run .
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080), нажмите «Добавить сайт» и введите полный URL. Первая проверка планируется сразу, как только освобождается место. Интервал отсчитывается от завершения предыдущей проверки этого сайта.

SQLite хранит адреса, проверки и инциденты в `data/monitor.db`. Данные сохраняются при перезапуске. Сервер слушает только `127.0.0.1`. Пока процесс остановлен, проверки не выполняются.

Поиск по названию и адресу обновляет список по мере ввода и учитывает регистр русских букв. Общая сводка показывает все отслеживаемые сайты. Для изменения порядка перетащите ручку слева от сайта или выберите её клавишей Tab и нажмите ↑ или ↓. Порядок сохраняется в SQLite, в том числе при перемещении в результатах поиска. Причина сбоя отображается под адресом и на странице сайта.

Кнопка «Изменить» открывает настройки названия, URL и интервала. История остаётся у записи сайта, включая смену адреса. При смене URL монитор планирует проверку нового адреса. Кнопка «Удалить» открывает раздел с подтверждением удаления сайта и всей его истории.

```powershell
go run . -port 8090 -db data/monitor.db -parallel 8 -timeout 5s
```

- Успешной считается проверка, получившая HTTP 2xx. Монитор следует HTTP-перенаправлениям.
- Задержка измеряется от начала запроса до получения заголовков последнего ответа.
- Первая неудачная проверка открывает инцидент. Следующие сбои добавляются в историю проверок. Первый успешный ответ закрывает инцидент.
- Полоса разбита на получасовые отрезки. Красный отрезок содержит хотя бы одну неудачную проверку, а процент считается по отдельным проверкам за сутки. Серые отрезки обозначают отсутствие измерений.

## Сборка для Windows

```powershell
go build -o uptime-monitor.exe .
.\uptime-monitor.exe
```

HTML, CSS и JavaScript встроены в исполняемый файл. Отдельная установка SQLite не требуется.
